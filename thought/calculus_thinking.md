# 微积分思想

> 两大视角：**微分**（变化率/局部）与**积分**（累积/整体）。把连续过程变为可计算的问题。

## 微分视角
1. 关注**变化率**：某量随时间/输入的变化速度，比总量更能揭示趋势。
2. 极值判定：变化率（导数）为 0 处可能是局部极值（最大/最小）。
3. 边际分析：增加一个单位的额外收益/成本，用于最优决策（边际收益 = 边际成本）。

## 积分视角
1. 累积效应：总量 = 变化率对时间的累积（求和取极限）。
2. 微元法：把复杂整体切成小单元 → 每单元局部近似 → 全部累加 → 取极限。
   - 例：曲线面积 = 无数小矩形之和；流量总量 = 速率曲线下的面积。
3. 平均与平滑：噪声数据用累积平均/积分平滑。

## Agent 使用要点
- 分析"趋势"问题：先找变化率（差分/斜率），再看拐点（趋势反转处）。
- 分析"总量"问题：把过程拆成时间片段/微元，逐步累加。
- 优化问题：比较边际增益决定是否继续投入。
- 数值上可用差分近似导数、累加近似积分，不必求闭式解。
