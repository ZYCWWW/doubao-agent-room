# 插值与拟合

> 给定离散数据点，构造一个连续模型描述其规律：**插值**精确过点，**拟合**近似整体趋势。

## 步骤
1. **收集离散观测**：明确自变量与因变量、数据范围与分布。
2. **选模型族**：
   - 线性（直线）——最简单，先试
   - 多项式/样条——数据有弯曲时
   - 幂律/指数/对数——增长/衰减类过程
3. **拟合参数**：最小化残差（观测值 - 模型值），常用最小二乘。
4. **评估拟合优度**：
   - 残差应随机分布、无系统性偏差（不该呈现"拱形"或"喇叭形"）
   - 警惕**过拟合**：模型复杂到只记住噪声，换数据就失效
   - 简单模型 + 可解释参数 优于 复杂模型 + 拟合漂亮

## 外推警告
- **插值（数据范围内）可信**，**外推（范围之外）必须谨慎**——模型只是拟合，不是定律。
- 外推前先问：范围外的规律是否可能改变（拐点、饱和、突变）？

## Agent 使用要点
- 用少量数据点推断趋势时：给出拟合模型 + 置信区间，不假装精确。
- 对比两个数据集：先归一化再拟合，避免量纲干扰。
- 预测未来：标注"基于当前趋势外推，可能存在拐点"。
- 数据噪声大：用平滑/回归而非强制过点插值。
