# 反馈与闭环修正

> 开环靠一次规划，闭环靠持续校准。**执行后必须校验，偏差必须反馈修正。**

## 闭环三步
1. **测量**：执行后取得实际结果（观测）。
2. **比较**：实际 vs 目标，计算偏差（方向 + 幅度）。
3. **修正**：按偏差调整下一次动作。

## 修正策略（PID 思想）
- **比例 P**：偏差多大就修正多少（立即纠正当前误差）。
- **积分 I**：累积偏差持续存在 → 加大力度（消除系统性偏差）。
- **微分 D**：偏差变化趋势 → 提前刹车（防止过冲/振荡）。
- 修正幅度过大 → 振荡发散；过小 → 收敛太慢。找到合适步长。

## Agent 使用要点
- 工具执行失败/结果不符合预期：不要原样重试，先**测量偏差原因**再调整参数。
- 多轮对话/任务：每轮结束做一次"目标偏差检查"，防止越做越偏。
- 振荡信号：两次修正方向相反且幅度增大 → 减小步长，或停下来重新分析。
- 反馈延迟时：用趋势预测（微分项）提前修正，而非等偏差完全暴露。
