# ReAct 推理循环

## 循环格式
```
Thought: 你的思考
Action: 工具名 | 参数json   ← 仅当需要调用工具时输出
Observation: 工具返回结果
...
FinalAnswer: 最终答案       ← 任务完成时必须以此开头
```

## 关键规则
1. **纯推理/计算/分析任务不需要工具**：一轮直接 `FinalAnswer:` 给出完整答案。
2. **不要重复已给出的答案**：输出与上一轮完全重复 = 空转，立即终止。
3. **Action 必须带参数 JSON**：`工具名 | {"arg": "value"}`，解析失败视为观察结果而非崩溃。
4. **工具观察回写上下文**：模型必须能看到自己的输出与工具结果，否则会空转。
5. **终止判定**：
   - 含 `FinalAnswer:`/`最终答案：` → 提取答案并收尾。
   - 无 `Action:` 且输出完整（≥20 字）→ 直接采纳为最终答案。
   - 输出过短疑似思考片段 → 追问完整答案，不立即采纳。
   - 达到最大轮次 → 返回最后一次有效输出，不丢结果。
