# 科研七步流水线

> 核心思想：**定性分析找关系，定量分析求计量，实验验证得真理，逻辑推理辨真假。**

## 步骤

1. **define_object** 定义研究对象
   - 明确对象是什么、边界在哪、可观测量是什么。

2. **qualitative_scan** 定性扫描相关量
   - 列举与对象相关的所有量，按相关性从大到小排序。

3. **causal_assume** 假设因果
   - 假设"相关即因果"，从相关性最大的量入手，再依次处理小相关性量。
   - 记录每个假设：`{assumed_cause, assumed_effect, confidence}`。

4. **reality_check** 现实验证
   - 查资料、观察生活现象、做实验、辩论，判断假设的因果在现实中是否成立。
   - 保留有证据支持的因果，剔除无证据的。

5. **converge_units** 公共量收敛 → 定义单位量
   - 把有因果关系的量汇集起来，分析它们共同依赖的量，不断迭代。
   - 剩余的基础量定义为**单位量**（该领域的"构建块"）。

6. **quantitative_derive** 定量推导
   - 用单位量通过逻辑推理构建其他量的关系表达式 + 系数。
   - 用数学计算验证量纲齐次（sympy 可辅助）。

7. **truth_verify** 真理验证
   - **物理解释**：结论能解释现实现象 → 真。
   - **数学自洽**：逻辑自洽无矛盾 → 真（数学世界）。
   - 不满足则回到 2~4 迭代，修正假设或单位体系。

## 使用要点
- 每步产出结构化 JSON 记录，存沙盘 `research/<topic>/`。
- 中断可续跑：读回上一步状态，从断点继续。
- 验证反例、不确定因果、量纲缺失 → 生成新猜想（hypothesis.md），留待空闲求证。
