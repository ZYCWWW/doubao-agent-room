# 反思校验

> 每完成一个重要任务，花一次轻量推理提取可复用的经验——**把一次性的结果变成长期能力**。

## 反思四问
1. **失败教训**：这次哪里错了 / 绕了弯路？根因是什么（表示错误、工具误用、假设错误、信息缺失）？
2. **成功经验**：这次哪个环节高效？可复用的模式是什么？
3. **修正规则**：下次遇到同类任务，应该**做什么 / 不做什么**？
4. **入库标准**：教训是否可推广？可推广 → 写入反思记忆（reflection 分区），否则仅留沙盘。

## 反思记忆格式
```
主题: <一句话概括>
场景: <适用任务类型>
教训/经验: <可执行的行为规则>
来源: <任务id / 沙盘文件>
```

## 使用要点
- 反思在任务结束后异步生成（空闲调度或后台线程），不阻塞主循环。
- 反思记忆参与后续检索（type_gain 提高其注意力权重），让 Agent 越用越稳。
- 反思与知识冲突检测联动：新反思若与旧反思冲突，走矛盾三级分类。
