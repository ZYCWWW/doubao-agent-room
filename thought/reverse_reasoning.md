# 逆向推理

> 正向走不通或太发散时，**从目标往回想**：要达到结果 R，必须先满足什么？

## 步骤
1. **明确目标状态**：终态是什么、可观测、可判定。
2. **反推前置**：要达到终态，最后一步必须满足什么条件？逐层往前。
3. **建必要条件链**：目标 ← 条件1 ← 条件2 ← … ← 当前状态。
4. **正反向交汇**：从当前状态正向推进、从目标反向推进，中间相遇即路径。
5. **回溯剪枝**：反推出的条件若与已知事实冲突，剪掉该分支。

## 应用
- **规划**：大目标 → 子目标 → 步骤。
- **排错**：症状 → 可能原因 → 验证（从现象反推链路，二分定位）。
- **证明**：要证 P，只需证 Q（Q→P），反复等价变形。
- **约束求解**：从答案反推限制条件，缩小搜索空间。

## Agent 使用要点
- 任务卡住时：不从头重推，从目标反推"缺哪一步"。
- 复杂要求：先列"完成 = 必须满足 N 个条件"，再逐项满足。
- 排错：列"什么原因会导致该症状"，按可能性/可验证性排序逐一排除。
