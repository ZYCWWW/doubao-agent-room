# 类比迁移

> 新问题像什么？把**结构**（关系网）从熟悉领域搬到陌生领域——比记忆单个事实强大得多。

## 类比四步
1. **找源域**：选择一个关系结构清晰、你已理解的领域（物理/生物/工程/日常）。
2. **建映射**：把目标域的对象一一对应到源域对象。
3. **保结构校验**：源域中的关系（大小/因果/顺序/包含）必须在目标域中成立——**不成立即映射失效**。
4. **导出结论**：把源域规律翻译到目标域，作为假设（而非事实）。

## 示例
- 电流 ↔ 水流（电压↔水位差，电阻↔管道粗细）
- 多世界重表示 ↔ 代数替换（主体↔人，数值↔钱）
- 记忆衰减 ↔ 放射性衰变（半衰期思想）

## Agent 使用要点
- 解释陌生概念：先给类比（源域），再标出类比失效处（避免误导）。
- 迁移解决方案：旧方案 → 新问题，必须逐条校验假设在新域是否成立。
- 类比生成的结论一律标记为"假设，待验证"，不能直接当事实。
- 校验失败的映射：换源域重试，不要硬凑。
