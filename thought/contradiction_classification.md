# 矛盾三级分类

> 遇到矛盾先分类，不同类的处理方式完全不同——**不是所有矛盾都意味着错误**。

## 三级分类

| 级别 | 判定 | 处理 |
|---|---|---|
| **logical_contradiction** | 同一符号体系、同一约束下自相矛盾（如 A>B 且 B>A 同时为真） | 阻断推理，回查前提或步骤，找出哪一步引入矛盾 |
| **representation_conflict** | 换个等效表示后矛盾消失（如 -1=1 换成主体/数值表示后成立） | **触发重表示**（见 multi_world_representation），不阻断 |
| **bridge_conflict** | 两个世界的桥接约束对不上（锚点冲突） | 修正桥接约束后重试，不轻易丢弃任一世界 |

## 判定流程

1. 发现矛盾等式/冲突断言。
2. 检查是否同一体系：是 → **逻辑矛盾**。
3. 是否可换载体/换符号系统消解：可 → **表示冲突**。
4. 是否桥接锚点不一致：是 → **桥接冲突**。
5. 否则按逻辑矛盾处理。

## 使用要点
- 想象空间 validator 与知识冲突检测都使用此分类。
- 逻辑矛盾必须阻断并定位到具体步骤（依赖图找环 / 未定义符号表）。
- 表示冲突与桥接冲突保留两条推理线，允许继续。
