# 多世界重表示推理

> 典型问题："假设昨天是明天，那么今天是星期五，问今天实际是星期几？"
> 直接设未知量会出现 -1=1 的伪矛盾——不是题目错了，是**表示载体选错了**。

## 核心思想

把"天"等**主体性量**用人/物体表示，把"数"用可交换的值表示；
把**实际关系**和**假设关系**用两套符号（T/F）分开标记，互不污染。

## 步骤

1. **识别伪矛盾**：设未知量求解出现 `-1 = 1` 这类荒谬等式。
2. **重表示**：为主体量找等效载体（人/物），为数值找载体（钱/数）。
   - 例：昨天→小红(A)，今天→小明(B)，明天→小张(C)；星期五→钱 5。
3. **双符号系统**：
   - `T(x)` = x 的实际值；`F(x)` = x 在假设世界中的值。
   - 桥接约束：`T(C) = F(C)`（"明天=小张"是两世界共享的锚点）。
4. **列方程**：
   - 实际关系：`T(A)+2 = T(C)`（三天差 2）
   - 假设关系：`F(C)=F(A)=F(B)-1`（假设中小红的钱是小张的，小明多 1）
   - 锚点：`F(B) = 5`（假设中今天=星期五）
5. **求解**：`T(A)=2, T(B)=3` → 今天星期三。
6. **保结构映射校验**：重表示后相对关系（差 1、顺序）必须在新的载体中一一保留，否则重表示无效。

## 与矛盾分类的配合
- 推理中出现**逻辑矛盾**（同一体系内自相矛盾）→ 阻断。
- 出现**表示冲突**（换个说法就通了）→ 触发重表示，用本架构。
- 出现**桥接冲突**（锚点对不上）→ 修正桥接约束后重试。
