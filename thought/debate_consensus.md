# 讨论与辩论收敛

## 角色
- **proposer** 提出观点/方案
- **critic** 反驳、找漏洞
- **constraint** 补充限制条件、边界
- **synthesizer** 汇总共识

## 收敛判定
```
consensus = 0.4*观点Jaccard + 0.4*LLM一致性 + 0.2*(1 - 反驳率)
```
- `consensus >= 0.75` 或轮次 >= 8 → 收敛，停止辩论。

## 结果分级
| 结果 | 处理 |
|---|---|
| 共识（is_verified） | 可写入记忆（事实/规则分区） |
| 分歧 | 只进沙盘，不污染知识库 |
| 开放问题 | 生成 hypothesis.md 候选，留待求证 |

## 使用要点
- 辩论用于：知识冲突仲裁、因果假设验证（reality_check）、复杂决策。
- 子 Agent 并行时默认用 light 模型，避免压垮本地 Ollama。
- 辩论结论必须带**证据来源**，无来源的共识不直接入库。
