# 证伪检验

> 科学检验的真谛：**找反例比找支持例更有价值。** 一条反例推翻全称命题；一百条支持例只能增加信心。

## 原则
1. **可证伪性**：一个断言必须是"存在某种证据能证明它错误"的，才谈得上科学验证。
2. **先攻反例**：验证假设时，优先设计能推翻它的检验，而非只找支持它的证据。
3. **边界**：找到反例后，缩小命题适用范围（"除非……否则成立"），而不是直接丢弃全部。
4. **对称警惕**：支持例存在选择性偏差（幸存者偏差）——没被看到的失败案例可能更多。

## Agent 使用要点
- 给结论前自问：什么证据会出现 → 但结论仍错？如果找不到，结论可能不可证伪。
- 验证模型/规律：构造极端/反例输入测试，而不是只跑正常用例。
- 评估别人的结论：看作者是否主动找了反例。
- 猜想闭环：证伪 ≠ 失败，证伪结果本身是知识（记录在案，不删猜想）。
