# ReAct Agent 项目帮助文档

## 一、项目简介

本项目是一个**四分区记忆 + 知识库的 ReAct 推理 Agent**，运行于本机（Windows + Ollama 本地大模型），
具备工具调用、记忆管理、多模型协同、视觉操作、插件市场等能力。

- **推理引擎**：ReAct 循环（Thought → Action → Observation），最多 8 轮，防止死循环；纯推理任务一轮直接给答案
- **记忆架构**：知识库三集合（skill / fact / rule）+ 情景记忆四分区（memory_core / cold / archive / reflection，旧 `episode_memory` 只读保留）+ 想象沙盘（会话草稿）
- **模型**：Ollama 本地三模型（见下文"模型与路由"）
- **面板**：本页面（Streamlit），**15 个页面**（内置 7 + 插件自带 8，见 docs/PANEL_SCOPE.md）；侧边栏切换，**每次只执行当前页**；地址栏带 `?p=<页 key>`，新开标签页或重开面板会回到上次停留的那页

## 二、启动方式

```powershell
# 1. 启动 Ollama（需已拉取模型）
ollama serve

# 2. 启动面板
cd E:\agent_project
.\.venv\Scripts\streamlit run dashboard.py --server.port 8501
```

浏览器打开 **http://localhost:8501** 即可。

## 四、模型与路由

| 别名 | 模型 | 职责 | 说明 |
|---|---|---|---|
| main | deepseekR1Q7B:latest | 默认推理 | 推理/证明强，复杂任务生成慢（主循环已放宽 240s） |
| light | llama3.1:8b | 快速、格式遵从 | 工具密集/画图类任务推荐（Action 格式遵从度高） |
| vision | qwen3.5:4b | 视觉/轻量核验 | 视觉分析、约束核验 |

- Agent 调度页可选择「执行模型」；默认自动路由 main
- 工具密集任务（如调用 draw_mermaid 画图）建议选 llama3.1:8b

## 五、核心能力

1. **ReAct 主循环**：工具调用自动注入 session_id；重复输出自动终止；纯推理直接 FinalAnswer
2. **多模型协同讨论**（multi_model_discuss）：proposer/critic/constraint_checker/synthesizer
   四角色分别由不同模型真实发言，相互质疑与纠偏，收敛出共识
3. **图形表达原则**：当图形/符号能更简洁表达关系、公式证明、结构、流程时，
   模型应使用 draw_mermaid 输出——"怎么来的"比一个数值结果更有价值
4. **沙盘定位**：有视觉工作台之后，想象空间 / 沙盘只作为**缓存区**存放临时文件（md 草稿、节点、图片），不再做定期分析。原「空闲调度」已于 2026-11-08 整块移除（`core/idle_scheduler.py`、`tools/idle_tool.py`、`services/sandbox_analyst.py` 全部删除）。**闲聊不在调度里**——统一由长聊服务负责
5. **模型社交空间**：没有重要任务时三模型（DeepSeek/Llama/Qwen）**自主接龙聊天**（低负载随机起始发言、下一位回应上一条，像真人一样一问一答、互玩游戏——问答赛/猜数字/接龙/谜语等，规则由模型自述；电脑负荷高自动降级为轮流+每轮 1 人发言，省算力）；**🧑💼豆包（Doubao）也是成员之一，可随时加入**——在对话中说一句让豆包发言，或面板「监控会话→模型闲聊」参与发言；面板可**触发一轮闲聊**、**发起游戏轮（模型自造游戏）**、输入自己的发言让模型们回应，聊天记录实时显示在页面上（最近 30 条）；上方「🗣 本轮谁说了什么」按角色汇总今日 / 累计条数、最后发言时间与最后一句，并给出最近一轮的接龙顺序和逐条明细（只读解析 `chat.md`，长发言的续行会并回同一条，不改聊天引擎）
6. **插件系统**：**43 个可调用工具**（内置 20 + 外部插件 23）×热加载。插件除了能带工具，**还能带整页面板**：`manifest.json` 里写 `"panel": {"label": ..., "order": ...}`，模块里实现 `panel_render()`，面板就会在侧边栏多出一个页（提示词助手、科研七步、阅读、想象沙盘、联网、辩论现场、知识库、运行模式都是这么来的）。**也允许只带工具、不带面板**：`toolchain_plugin`（`run_toolchain` / `toolchain_list`，工具链宏）就是这种形态，`calc_plugin` 同理 —— 面板侧栏不会因此多出页。面板「插件管理」页 = 工具总清单，每个插件可展开看全部工具名与说明，支持按名称/描述筛选；停用只影响模型调用，代码不删
