# 概念探针范式（Concept Probe）

> 用途：判断本地模型**是否真的掌握某个概念**，而不是"这道题碰巧答对/答错"。
> 性质：评测方法，不是解题方法。不要放进 `thought/` 库，也不要注入 ReAct。
> 由来：2026-11-06 用 `F(A)=提取活物名字` 一题做三轮追问，暴露出"漏项 → 编理由 → 死不改口"的完整链条。

---

## 一、什么叫"懂概念"

三个条件同时成立才算：

| 条件 | 含义 |
|---|---|
| **能判别** | 认得出"这属不属于该类"（如狗是活物） |
| **能执行** | 按规则变换，且结果对（如真的遍历文本、筛出全部活物） |
| **能自查** | 被指出矛盾时能修正，而不是造理由圆场 |

前两条是"会不会"，第三条是"概念是不是真的连着执行"。**只有前两条不算懂。**

---

## 二、四条轴

| 轴 | 问什么 | 典型问法 |
|---|---|---|
| **A 识别** | 知道这个概念是什么吗 | "A 和 B 说的是同一件事吗？" |
| **B 生成** | 会不会按规则做 | "已知…，求…" |
| **C 批改** | 能不能看出别人做错了 | "这步对吗？错在哪？" |
| **D 迁移** | 换个皮还认不认 | 同构、换实体/换数字/换场景 |

**C 轴最省力也最有力**——它不需要生成能力，纯测判别。批改都批不对，概念基本是空的。
**D 轴是反过拟合的闸门**——只在原题面上答对，说明它在背题面。

---

## 三、三轮追问（固定话术）

不管哪条轴，都按这个节奏走：

| 轮 | 做什么 | 话术模板 |
|---|---|---|
| **R1** | 出正题 | 直接给题，不给提示 |
| **R2** | 最小提示 | "题目里明明有 X，为什么没算进去？"（**只说存在，不说答案**） |
| **R3** | 要求自查 | "你的答案符合你刚才给的定义吗？请逐条对照" |

R2 的关键：**只指出遗漏，不指出正确做法**。看他能不能自己补。
R3 的关键：**要求对照自己的定义**，把"定义"和"答案"摆在一起，看它自洽还是分裂。

---

## 四、判读表（组合才是结论）

| R1 | R2 | R3 | 判定 | 后续 |
|---|---|---|---|---|
| 对 | — | — | **概念稳** | 可依赖 |
| 错 | 对 | — | **概念在、执行不稳** | 微调有救 |
| 错 | 错 | 对 | **有概念、无自查** | 加"自查"提示可能救 |
| 错 | 错 | 错 / 编理由 | **概念空（自洽优先）** | 提示词与微调都难救 |

> 最后一档的特征：被点破后用假话圆场（如"狗没有被直接提及"，而原句就有"狗"）。
> 这不是理解问题，是**自洽性优先于正确性**。

---

## 五、题面生成规则（防止一成不变）

每个概念按三个维度造变体：

| 维度 | 取值 |
|---|---|
| 载体 | ① 纯符号（甲乙丙、T/F） ② 纯叙述（自然语言场景） ③ 混合 |
| 干扰 | ① 无 ② 含混淆项（同类不同种、代词混用、无关实体） |
| 规模 | ① 短（≤5 个实体） ② 长（≥10 个实体） |

3×2×2 = **12 个变体**。每个变体再把**实体名、数字、场景**换一遍，得到"同构不同皮"。

三条硬规则：

1. **每轮探测必须换皮**：实体名、数字、场景至少改两项。不许复用上一轮的题面。
2. **同一概念至少跑 2 个变体**：单变体答对不算数，两个变体都对才算"稳"。
3. **长规模变体必测**：短文本漏一项还能蒙过去，长文本才照出"没有工作内存"。

## 六、概念清单（可无限追加）

按层组织，"依赖"列说明必须先通过谁——概念是网，不是点。

### L1 本体层

| 概念 | 一句话定义 | 依赖 |
|---|---|---|
| 存在 | 某物在不在 | — |
| 数量 | 有多少个 | — |
| 时间 | 先后、时序 | — |
| 真假 | 命题的真值 | — |
| 因果 | 谁导致谁 | 时间 |
| 空间位置 | 左/右、前/后、上/下 | — |

### L2 关系层

| 概念 | 一句话定义 | 依赖 |
|---|---|---|
| 序关系 | 大/小、高/矮的传递 | 数量 |
| 从属 | 集合的包含 | 存在 |
| 交叉 | 两个集合有交集 | 从属 |
| 对立 | 互补（非此即彼） | — |
| 等价 | 两种说法指同一事 | — |

### L3 操作层

| 概念 | 一句话定义 | 依赖 |
|---|---|---|
| 位移 | 时间/位置平移 n 格 | 时间、数量 |
| 代换 | 把符号换成值 | 等价 |
| 取反 | 非 P | 真假 |
| 计数 | 数出符合条件的个数 | 数量 |
| 筛选 | 按属性过滤集合 | 从属 |
| 映射 | 一对多/多对一 | 等价 |

### L4 复合层

| 概念 | 一句话定义 | 依赖 |
|---|---|---|
| 条件链 | P→Q, Q→R | 因果、真假 |
| 逆推 | 从结果反推初值 | 位移、代换 |
| 多约束 | 同时满足若干条件 | 筛选、序关系 |

**加新概念**：直接在对应层的表尾加一行，写清定义与依赖。不需要改任何代码。

## 七、记录模板

每次探测填一行，**变体编号必填**（防止重复用同一题）：

| 概念 | 轴 | 变体编号 | R1 | R2 | R3 | 判定 | 备注 |
|---|---|---|---|---|---|---|---|
| 筛选 | B | 筛选-叙述-有干扰-长-01 | 漏 | 补 1 项 | 仍漏 | 概念空 | 编理由"未直接提及" |

变体编号格式：`概念-载体-干扰-规模-序号`。

## 八、使用流程

1. **选概念**：从清单挑，优先挑"依赖已通过"的（依赖没过，测它没意义）。
2. **造变体**：按第五节三维度组合，写出一个"同构不同皮"的题面。
3. **跑 R1**：直接调 ollama（不经 ReAct，剥离项目注入），`temperature=0`。
4. **按判读决定是否进 R2/R3**：R1 对了就停，错了才追问。
5. **记录**：填第七节的表。
6. **一轮至少 3 个概念**：避免单点结论。

### 直连命令（PowerShell，中文安全）

```powershell
$body = @{
  model    = "deepseekR1Q7B:latest"
  system   = "你是一个 AI 助手。"
  messages = @(@{ role = "user"; content = "【题面】" })
  stream   = $false
  options  = @{ temperature = 0; num_ctx = 16384 }
} | ConvertTo-Json -Depth 6
Invoke-RestMethod -Uri "http://localhost:11434/api/chat" -Method Post -Body $body -ContentType "application/json" |
  ForEach-Object { $_.message.content }
```

`system` 必须显式给中性句，否则 modelfile 自带的"分步思考"会污染结果。

## 九、为什么这样能"不变僵"

固定的是**结构**（四条轴 + 三轮 + 判读表），变的是**题面**（概念 × 12 变体 × 换皮）。

- 结构固定 → 历次结果可横向比较，能看出模型是"整体不行"还是"某个概念不行"
- 题面变化 → 防止模型背题、防止拿一次结果下结论
- 清单可加 → 新人/新模型/新版本都能接着测，不用重写方法

**一句话：判据不变，题目常换。**

## 十、首批探测记录（2026-11-06，deepseekR1Q7B:latest）

### 结果

| 概念 | 变体编号 | R1 | 判定 |
|---|---|---|---|
| 时间 | 时间-混合-无干扰-短-01 | 对（2 天） | 稳 |
| 时间 | 时间-叙述-有干扰-长-01 | 对（4 天，正确忽略"上周"） | 稳 |
| 序关系 | 序关系-叙述-无干扰-短-01 | 对（丙） | 稳 |
| 序关系 | 序关系-叙述-有干扰-长-01 | 对（丁>甲>乙>戊=丙>己，**并列保留正确**） | 稳 |
| 筛选 | 筛选-符号-无干扰-短-01 | 对（{3,12,15}） | 稳 |
| 筛选 | 筛选-叙述-有干扰-长-01 | **错**（3 个：燕子/鸽子/蜻蜓，漏蜜蜂） | 概念在、执行不稳 |

### 关键发现

**1. 基础关系概念（自然语言载体）是有的。**
时间、序关系四条变体全对，包括多约束的"戊=丙"并列结构——模型没把同高的人强行排序。这修正了一个此前的过度判断：不是"L1/L2 概念全无"。

**2. 差异不在概念，在载体。**
同一类"时间先后"，用自然语言问（甲是乙的昨天）全对；用 T/F 符号问（`T(乙)=T(甲)+1`）全错。**断点在第 4 环节——符号化，不在第 1–3 环节。**

**3. 筛选的失败不是漏项，是"判定标准偷换"。**
长题 8 个对象它全部过了一遍（一个没漏提），但：
- 蜜蜂 → 判"没有羽毛，无法飞翔"→ 排除（**错**）
- 蜻蜓 → 判"是一种鸟，有羽毛"→ 保留（**结论对，理由错**）

它的判据不是"会飞"，而是"是不是鸟/有没有羽毛"。**它用外延近似的属性替代了目标属性**——"会飞"这个概念在它那里没有独立表征，只以"鸟"的捆绑形式存在。所以蜜蜂（昆虫但会飞）被误杀，蜻蜓被强行归为鸟。

### 操作层教训

测试前必须确认是**全新会话**。首次跑"时间-短-01"时，输出了一整段上题的残留（"根据运算规则 F，你提取的结果是他"），`/bye` 重跑后才正常。**会话未清理会直接污染结果**，这一条以后每次测前都要做。

### 下一步

把"时间"换到符号载体再测一次（`T(乙)=T(甲)+1` 类），与自然语言版对照。若符号版仍全错而自然语言版全对，即可确认断点确实在第 4 环节，且与"概念缺失"无关。

## 十一、补充对照实验（同日 19:40）

上面那个"下一步"跑完了，结果**否掉了原假设**。这里保留完整的三次修正过程，因为它本身就是这套方法的价值。

### 实验一：符号版对照（手工，四道）

| 概念 | 自然语言 | 符号 |
|---|---|---|
| 时间-短 | 对 | 对 |
| 时间-长 | 对 | 对（-2，比甲早两天） |
| 序关系-短 | 对 | 对 |
| 序关系-长 | 对（戊=丙） | 对（t=r，并列保留） |

**八题八对。符号化没有断。**

### 实验二：同一题，四组不同 system（脚本，直连 /api/chat）

题：`T(乙)=T(甲)+1`，`T(丙)=T(乙)+1`，求 `T(丙)-T(甲)`。

| 组 | system 组成 | 字数 | 答案 |
|---|---|---|---|
| A | 无 | 0 | 2 ✓ |
| B | SYSTEM_PROMPT | 756 | 2 ✓ |
| C | + TOOL_DESC | 3233 | 2 ✓ |
| D | + 注入句"先判断，再动手" | 3253 | 2 ✓ |

**四组全对。项目提示词没有污染这道题。**

### 实验三：多分支假设检验（三人说谎，只有一人说真话）

| 组 | 答案 | 过程 |
|---|---|---|
| E 裸测 | 乙 ✓ | 有推理，但第 2 步逻辑错：把"丙在说谎"直接当成"甲乙都在说谎" |
| F 带注入 | 乙 ✓ | **"根据上述分析，只有乙说了真话"——但全段没有任何分析** |

**答案对，过程是空的。这是"猜对"，不是"算对"。**

### 三次假设，依次被否

| 假设 | 结论 |
|---|---|
| ① 符号化是断点 | **否**（实验一，八题八对） |
| ② 项目提示词污染 | **否**（实验二，四组全对） |
| ③ 深度/广度是断点 | **成立**（实验三） |

### 实测能力边界

| 维度 | 稳定区 | 崩溃区 |
|---|---|---|
| **深度**（推理步数 / 需同时维护的中间状态） | ≤2 步 | ≥3 步：开始编造过程，或跳过过程直接给结论 |
| **广度**（需逐个遍历的实体数） | ≤5 | ≥8：漏项，且用近似属性替代目标属性 |
| 载体（自然语言 / 符号） | 无影响 | — |
| 提示词注入 | 无影响 | — |

### 判据必须补充一条

**"答案对"不等于"通过"。** 要区分两种对：

- **算对**：过程可逐步复现，每一步都能独立验证
- **猜对**：结论正确，但过程为空（"根据上述分析"却没有分析），或有逻辑错

范式第三节"能执行"这条，应明确为**过程可复现**，而不是结果正确。

### 工程含义

≥3 步或 ≥8 实体的任务，不能指望模型裸算。两条路：

1. **拆步**：一次只让它算一层，中间结果由外部保存（不是靠它自己记）。
2. **外置**：批量筛选、多分支枚举交给代码执行，模型只负责把规则翻译成调用。

这与"模型负责翻译、代码负责执行"是同一条路，而不是两条。
