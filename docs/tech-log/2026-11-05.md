其中他贡献了两段方法论，不是需求而是**思路**：

1. **猜想的科研流程**（U10）：定性分析 → 对相关量做相关性分析 → 假设相关即因果 → 先大后小 → 找资料 / 观察现实验证因果 → 汇集有因果关系的量 → 找它们共同的关系量 → 迭代 → 最后按因果量化。
2. **等效概念替换**（U11）："昨天是明天、今天是星期五"这种题，用实数未知量会导到 `-1 = 1`；
   换成"天 ↔ 人、天的关系是差 1、星期五 ↔ 钱"，把时间题变成钱题就成立了。这条后来成了思维库里的范例。
